# Security Policy

## Supported Versions

Only the latest release receives security fixes.

| Version | Supported |
|---|---|
| Latest (2.x) | ✅ |
| Older | ❌ |

## Reporting a Vulnerability

**Please do not open a public GitHub issue for security vulnerabilities.**

Send a description of the issue to **jviaches@gmail.com** with:

- A summary of the vulnerability
- Steps to reproduce
- Potential impact
- Any suggested fix (optional)

You will receive a response within **72 hours**. Once the issue is confirmed and a fix is released, you will be credited in the release notes (unless you prefer to remain anonymous).
